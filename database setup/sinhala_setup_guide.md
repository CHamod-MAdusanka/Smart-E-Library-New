# XAMPP භාවිතා කර පද්ධතිය Localhost හි ස්ථාපනය කිරීමේ සම්පූර්ණ මාර්ගෝපදේශය

මෙම පද්ධතිය (Smart E-Library) ඔබගේ පරිගණකයේ ධාවනය කිරීම සඳහා සහ දත්ත සමුදාය (Database) සම්බන්ධ කිරීම සඳහා පහත පියවර අනුගමනය කරන්න.

---

## පියවර 1: XAMPP ක්‍රියාත්මක කිරීම (Start XAMPP)

1. ඔබගේ පරිගණකයේ ඇති **XAMPP Control Panel** එක විවෘත කරන්න.
2. එහි ඇති **Apache** සහ **MySQL** යන දෙකටම ඉදිරියෙන් ඇති **"Start"** බොත්තම ක්ලික් කරන්න.
3. ඒ දෙකම කොළ (Green) පැහැයට හැරෙන තෙක් සිටින්න.

---

## පියවර 2: ව්‍යාපෘතිය htdocs වෙත පිටපත් කිරීම

1. ඔබගේ පරිගණකයේ ඇති ව්‍යාපෘති ෆෝල්ඩරය (Project Folder) වන `Smart-E-Library-IoT-Management-System-.Github.io-main` ෆෝල්ඩරය **Copy** කරගන්න.
2. දැන් `C:\xampp\htdocs\` යන ස්ථානයට ගොස් එය එහි **Paste** කරන්න.
3. *පහසුව සඳහා,* Paste කළ ෆෝල්ඩරයේ නම `library` ලෙස වෙනස් (Rename) කරන්න. 

---

## පියවර 3: දත්ත සමුදාය (Database) සැකසීම

1. ඔබගේ Web Browser එක (Google Chrome / Firefox) විවෘත කර **http://localhost/phpmyadmin** වෙත යන්න.
2. වම් පස මෙනුවේ ඉහළින්ම ඇති **"New"** යන්න ක්ලික් කරන්න.
3. *Database name* යන ස්ථානයේ **`smart_e_library`** ලෙස ටයිප් කර, දකුණු පස ඇති **"Create"** බොත්තම ඔබන්න.
4. දැන් වම් පසින් ඔබ සෑදූ `smart_e_library` යන නම දිස්වනු ඇත. එය ක්ලික් කරන්න.

---

## පියවර 4: දත්ත සමුදාය (SQL File) Import කිරීම

1. `smart_e_library` දත්ත සමුදාය තෝරාගත් පසු, ඉහළින් ඇති මෙනුවෙන් **"Import"** ටැබ් එක (Tab) ක්ලික් කරන්න.
2. ඉන්පසු **"Choose File"** (හෝ Browse) බොත්තම ඔබන්න.
3. ඔබගේ ව්‍යාපෘති ෆෝල්ඩරය තුළට ගොස් (උදා: `C:\xampp\htdocs\library\`) එහි මා විසින් සාදාදුන් **`smart_e_library.sql`** නම් ගොනුව තෝරාගන්න (Select කර Open කරන්න).
4. ඉන්පසු පිටුවේ පහළටම ගොස් **"Import"** (හෝ "Go") බොත්තම ක්ලික් කරන්න.
5. "Import has been successfully finished" ලෙස කොළ පැහැති පණිවිඩයක් පැමිණේවි. (මෙමගින් සියලුම පොත්, සහ පරිශීලක දත්ත සාර්ථකව පද්ධතියට ඇතුළත් වේ.)

---

## පියවර 5: පද්ධතියට පිවිසීම (Accessing the System)

1. දැන් නැවතත් ඔබගේ Web Browser එකේ අලුත් Tab එකක් විවෘත කරන්න.
2. එහි **http://localhost/library/** ලෙස ටයිප් කර Enter කරන්න. (ඔබ ෆෝල්ඩරයේ නම වෙනස් නොකළේ නම් ෆෝල්ඩරයේ සම්පූර්ණ නම ලබා දිය යුතුය).
3. දැන් ඔබට පුස්තකාල පද්ධතියේ ප්‍රධාන පිටුව (Login Page) දැකගත හැකි වනු ඇත.
